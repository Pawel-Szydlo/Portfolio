# Technology icons

The brand SVGs in this directory are bundled locally so the portfolio does not depend on a third-party CDN at runtime.

- React, TypeScript, Next.js, Tailwind CSS, Storybook, Bun, Redux, Vite and Webpack: [Simple Icons](https://github.com/simple-icons/simple-icons)
- Playwright: [official Playwright website](https://playwright.dev/)

Review the respective brand guidelines before using these marks outside this portfolio.
